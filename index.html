Cara beli preset.

Untuk versi gratis, pembayaran dikonfirmasi manual melalui WhatsApp.

1

Pilih preset

Tekan tombol pesan pada produk. Nama produk dan harga akan otomatis masuk ke pesan WhatsApp.

2

Bayar & konfirmasi

Admin mengirim detail rekening atau QRIS milik penjual. Pembeli mengirim bukti pembayaran untuk diverifikasi.

3

Terima file XML

Setelah pembayaran valid, admin mengirim file XML dan petunjuk impor melalui WhatsApp atau tautan file pribadi.

Keamanan: jangan pernah meminta PIN, password, atau kode OTP pembeli. Gunakan QRIS resmi dari penyedia pembayaran atau rekening atas nama penjual. Jangan unggah file XML berbayar ke tautan publik tanpa mempertimbangkan risiko file dibagikan ulang.
Setelah membeli

Cara pakai file XML.

01

Unduh file

Simpan file XML dari chat atau tautan yang diberikan admin ke HP Android kamu.

02

Buka Alight Motion

Impor proyek atau preset menggunakan metode yang didukung versi Alight Motion kamu. Nama menu bisa berbeda antarversi.

03

Sesuaikan editan

Ganti teks, klip, warna, dan musik sesuai kebutuhan. Beberapa font atau efek mungkin perlu dipasang terpisah.

FAQ

Apakah preset langsung bisa dipakai?

Preset perlu diuji di versi Alight Motion yang sesuai. Efek, font, atau fitur tertentu bisa berbeda di tiap perangkat.

Apakah pembayaran otomatis?

Belum. Versi awal ini memakai konfirmasi manual. Website statis tidak bisa memverifikasi transfer atau mengirim file aman secara otomatis tanpa layanan tambahan.

Bagaimana menerima file?

Setelah pembayaran diverifikasi admin, file XML dikirim lewat WhatsApp atau tautan unduhan yang disiapkan penjual.

Bisakah minta bantuan?

Gunakan tombol pesan dan tulis kendala yang kamu alami. Admin dapat memberi panduan impor sesuai versi aplikasi.
